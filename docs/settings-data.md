# 설정과 데이터 보관

봇이 무엇을 어디에 저장하는지, 어떻게 백업하고 되살리는지 정리합니다.
설정은 대부분 대시보드의 **운영자 패널**에서 고치며, 파일을 직접 고칠 일은 `.env` 정도입니다.

## 어디에 무엇이 있나

| 자리                         | 담는 것                                                                                                                             | 지워지면                                                                  |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `.env`                       | 봇 토큰 · 클라이언트 시크릿 · `SECRETS_KEY` · `SESSION_SECRET` 같은 비밀과 기동 값                                                  | 봇이 켜지지 않습니다. `SECRETS_KEY` 를 잃으면 아래 암호화한 값도 잃습니다 |
| `database/settings.db`       | 운영자 패널에서 정한 설정 전부(운영 조절값 · 자동재생 장르 · 활동 문구 · AI 설정 · 프롬프트 · 서버별 설정) + 암호화한 API 키 · 쿠키 | 설정이 모두 기본값으로 돌아갑니다. 스냅샷에서 되살리세요                  |
| `database/backups/`          | `settings.db` 의 스냅샷                                                                                                             | 되살릴 곳이 없어집니다                                                    |
| `database/state.db`          | 저장된 대기열 · 음성 채널 상태 문구 · 재생 패널 자리                                                                                | 다시 켤 때 대기열을 이어 틀지 못합니다                                    |
| `database/cache.db`          | 받은 곡 색인 · 링크 장부 · SponsorBlock 구간 캐시                                                                                   | 곡을 다시 찾고 다시 받습니다                                              |
| `database/sessions.db`       | 대시보드 로그인 세션                                                                                                                | 다시 로그인하면 됩니다                                                    |
| `database/dashboard/favicon` | 꾸미기 탭에서 올린 파비콘 그림                                                                                                      | 봇의 프로필 그림으로 돌아갑니다                                           |
| `audio_cache/`               | 받은 곡 파일                                                                                                                        | 다시 받습니다                                                             |

- `settings.db` 는 봇이 지우지 않습니다. 봇을 업데이트해 구조가 맞지 않으면 열지 않고 멈춥니다(그 버전의 봇으로 켜세요).
- `state.db` · `cache.db` 는 구조가 바뀌면 봇이 새로 만듭니다. 운영자 패널의 캐시 초기화는 `cache.db` 와 받은 곡 파일만 지웁니다(대기열 · 설정은 남습니다).

## `SECRETS_KEY`

운영자 패널에서 넣은 API 키(Spotify · Last.fm · ListenBrainz · AI 서비스)와 유튜브 쿠키는 `SECRETS_KEY` 로 암호화해 `settings.db` 에 둡니다.
그래서 DB 파일이나 스냅샷만으로는 키를 읽을 수 없습니다.

- `SECRETS_KEY` 는 `.env` 에만 있습니다. **`.env` 를 DB 와 따로, 안전한 곳에 백업하세요.**
- 키를 바꾸거나 잃으면 저장해 둔 키 · 쿠키를 풀 수 없어 다시 넣어야 합니다. 다른 설정은 그대로입니다.

## 스냅샷

봇이 `settings.db` 를 자동으로 `database/backups/` 에 남깁니다.

| 종류        | 언제                                                                 | 남기는 수 |
| ----------- | -------------------------------------------------------------------- | --------- |
| 매일        | 하루 한 번(켤 때 오늘 것이 없으면 + 켜져 있는 동안 한 시간마다 확인) | 7         |
| 가져오기 전 | 설정을 가져오기 직전                                                 | 둘 합쳐 5 |
| 되살리기 전 | 스냅샷으로 되살려 바꿔 끼우기 직전                                   |           |

스냅샷 안의 비밀값은 암호문 그대로라, 같은 `SECRETS_KEY` 일 때만 풀립니다.

### 되살리기

**대시보드에서**: 운영자 패널 → 설정 탭 → 설정 스냅샷에서 고르고 "되살리기". 봇이 곧바로 다시 시작하며 바꿔 끼웁니다(지금 설정은 "되살리기 전" 스냅샷으로 남습니다).
`pnpm start` 없이 켠 봇이면 걸어만 두었다가 다음에 켤 때 바꿉니다.

**봇이 켜지지 않을 때(손으로)**:

1. 봇을 끕니다.
2. `database/settings.db` 를 다른 곳에 옮겨 둡니다(`settings.db-wal` · `settings.db-shm` 이 있으면 함께).
3. `database/backups/` 에서 되살릴 `settings-….db` 를 `database/settings.db` 로 복사합니다.
4. 봇을 켭니다.

> [!IMPORTANT]
> 되살리기 전에 `settings.db` 를 열어 둔 프로그램(SQLite 뷰어 등)을 닫으세요. Windows 에서는 열린 파일을 바꿀 수 없어, 봇이 까닭을 알리고 멈춥니다.

## 내보내기 · 가져오기

운영자 패널 → 설정 탭 → 설정 내보내기 · 가져오기.

- **내보내기**: ZIP 파일 하나를 내려받습니다. 안에는 `settings.json`(사람이 읽을 수 있는 설정)과 `favicon/`(올린 그림)이 들어 있습니다.
  **API 키 · 쿠키는 들어가지 않습니다.** 다른 PC 로 옮기면 키는 다시 넣어야 합니다.
- **가져오기**: 파일을 올리면 항목마다 지금과 같은지 · 다른지 · 가져올 수 없는지(까닭)를 보여 줍니다. 고른 항목만 파일의 것으로 통째 바뀝니다.
  저장할 때와 같은 검사를 거치며, 하나라도 걸리면 아무것도 바꾸지 않습니다. 가져오기 직전에 스냅샷을 남깁니다.
- 서버별 설정은 디스코드 서버 ID 로 묶여 있어, 다른 봇 계정으로 옮기면 그 봇이 들어간 서버에만 의미가 있습니다.

내보내기 · 가져오기 · 스냅샷 되살리기는 대시보드에 로그인한 지 10분 안이어야 합니다. 지났으면 로그인 창이 뜨고, 마치면 하던 일을 이어서 합니다.

## SQLite 프로그램으로 DB 를 볼 때

DB 는 [DB Browser for SQLite](https://sqlitebrowser.org/) 같은 프로그램으로 열어 볼 수 있습니다.

- **읽기 전용으로 여세요.** 대시보드에서 다루지 않는 것을 손으로 고치면 봇이 예상하지 못한 상태가 됩니다(받은 곡의 파일 경로를 고치면 캐시 정리가 그 경로의 파일을 지우는 식).
- **봇이 켜져 있는 동안 `settings.db` 를 고치지 마세요.** 봇은 설정을 켤 때 메모리에 올려 두고 쓰므로 바깥에서 고친 것을 모릅니다. 대시보드에서 저장하면 덮어쓰거나 "그사이 바뀌었어요"로 거절됩니다.
- 프로그램이 DB 를 열고 있는 동안에는 봇의 쓰기가 잠깐씩 막힐 수 있습니다. 다 봤으면 닫으세요.
- API 키 · 쿠키 칸은 암호문이라 읽을 수 없습니다.

## 파일 권한

- **Linux · macOS**: `.env` · DB 파일 · 스냅샷 · 쿠키 임시 파일은 봇을 돌리는 사용자만 읽고 쓰게(0600) 만듭니다.
- **Windows**: 이 권한이 먹지 않습니다. 봇 폴더의 권한을 따르므로, **봇 폴더는 다른 사용자와 같이 쓰지 않는 곳**(자기 사용자 폴더 아래 등)에 두세요.

암호화는 DB 사본이 새는 것을 막을 뿐, 봇 폴더에 쓸 수 있는 사람(`.env` 를 바꿀 수 있는 사람)은 막지 못합니다.
대시보드의 마지막 열쇠는 운영자의 디스코드 계정이므로, **디스코드 계정에 2단계 인증을 켜 두세요.**
