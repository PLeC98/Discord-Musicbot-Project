`.env` 파일에는 봇을 켜기 전에 정해야 하는 값만 넣습니다.<br>
이곳에 없는 대부분의 설정은 대시보드의 운영자 패널에서 찾을 수 있습니다.<br>
(예시: 외부 서비스 API 키, 자동재생, 상태 문구, 임베드 색 등)

`.env`가 없으면 `pnpm install`이나 첫 실행 때 `.env.example`을 복사해 만들고, 시크릿 키(`SECRETS_KEY`)를 채워 둡니다.<br>
값을 바꾼 뒤에는 봇을 다시 시작해야 적용됩니다.

> [!NOTE]
>
> - 한 줄에 `이름=값` 하나씩 씁니다. 값을 비워 두면 기본값을 씁니다.
> - Windows 경로(`C:\ffmpeg\bin\ffmpeg.exe`)는 그대로 써도 됩니다. 따옴표로 감쌀 때는 작은따옴표를 쓰세요. 큰따옴표 안에서는 `\n` 같은 글자가 줄바꿈으로 읽힙니다.
> - 상대 경로는 봇 폴더를 기준으로 합니다.

## 라이선스

| 이름              | 기본값               | 설명                                                                                                                                               |
| ----------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SOURCE_REPO_URL` | 이 프로젝트의 저장소 | 코드를 고쳐서 운영한다면, 고친 코드를 공개한 저장소 주소를 넣으세요. `/license` 명령어가 이 주소를 보여 줍니다. 코드를 고치지 않았다면 비워 두세요 |

이 봇은 AGPL 라이선스라, 코드를 고쳐서 다른 사람이 쓰게 운영한다면 그 코드를 공개해야 합니다.<br>
주소는 어느 저장소든 넣을 수 있습니다. 다만 대시보드의 "설명서" 버튼은 GitHub과 GitLab 주소만 지원하므로, 다른 곳의 주소면 이 버튼이 보이지 않습니다.

## 필수값

| 이름            | 넣을 값                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------- |
| `DISCORD_TOKEN` | 봇 토큰. [디스코드 개발자 포털](https://discord.com/developers/applications)의 봇 → 토큰 |
| `CLIENT_SECRET` | 클라이언트 시크릿. 개발자 포털의 OAuth2 → 클라이언트 정보. 대시보드 로그인에 씁니다      |

둘 중 하나라도 비어 있으면 봇이 켜지지 않고, 비어 있는 이름을 알려 줍니다.<br>
`CLIENT_SECRET`이 틀리면 봇은 켜지지만 대시보드에 로그인할 수 없습니다. 봇을 켤 때 디스코드에 맞는 값인지 확인해, 틀렸으면 로그로 알려 줍니다.

## 대시보드

| 이름             | 기본값                  | 설명                                                                                                                                                                          |
| ---------------- | ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DASHBOARD_PORT` | `33333`                 | 대시보드 포트                                                                                                                                                                 |
| `DASHBOARD_URL`  | `http://localhost:포트` | 브라우저 주소창에 입력하는 대시보드 주소(경로 없이, 예: `https://music.example.com`). 디스코드 로그인이 이 주소로 돌아오므로 기본값과 다른 주소로 접속한다면 꼭 넣어야 합니다 |

`DASHBOARD_URL`을 바꿨다면, 봇을 켤 때 로그에 나오는 "디스코드 개발자 포털 OAuth2 → Redirects에 등록할 주소"를 개발자 포털에 다시 등록하세요.

다른 PC나 휴대폰에서 대시보드를 열 때 쓰는 고급 설정(`DASHBOARD_TLS_CERT`, `DASHBOARD_TLS_KEY`, `DASHBOARD_TRUST_PROXY`, `DASHBOARD_HOST`, `DASHBOARD_ALLOW_PLAINTEXT`)은 [대시보드 외부 접속 설명서](dashboard-network.md)를 참고하세요.

## ffmpeg

봇은 ffmpeg로 음악을 변환합니다. 봇을 켤 때 Windows와 Linux용 ffmpeg를 자동으로 다운로드합니다(봇 업데이트로 버전이 바뀌었을 때도).

| 이름          | 기본값 | 설명                                                                                 |
| ------------- | ------ | ------------------------------------------------------------------------------------ |
| `FFMPEG_PATH` | 비움   | 직접 설치한 ffmpeg 실행 파일 경로. 넣으면 자동 다운로드를 하지 않고 이 파일을 씁니다 |

`FFMPEG_PATH`를 비워 두면 다운로드한 ffmpeg를 먼저 찾고, 없으면 시스템에 설치된 ffmpeg(PATH)를 씁니다.

> [!NOTE]
> **macOS는 자동 다운로드를 하지 않습니다**(macOS용 빌드가 없습니다). `brew install ffmpeg`로 설치하면 그대로 쓸 수 있고, 다른 곳에 설치했다면 `FFMPEG_PATH`로 지정하세요.

## 로그

| 이름               | 기본값         | 설명                                                                                                                |
| ------------------ | -------------- | ------------------------------------------------------------------------------------------------------------------- |
| `LOG_LANGUAGE`     | 비움           | 로그, 터미널 출력 언어(예: `ko`). 비우거나 지원하지 않으면 OS 언어(Windows는 지역 형식), 그것도 아니면 한국어입니다 |
| `LOG_FILE_ENABLED` | `true`         | `false`면 로그 파일을 남기지 않습니다. 대시보드에서 지난 로그 보기도 꺼집니다                                       |
| `LOG_FILE`         | `logs/bot.log` | 로그 파일 경로                                                                                                      |
| `LOG_FILE_MAX_MB`  | `20`           | 로그 파일이 이 크기(MB)를 넘으면 새 파일로 나눕니다. `0`이면 나누지 않습니다                                        |
| `LOG_FILE_KEEP`    | `5`            | 나눈 로그 파일을 몇 개까지 남길지. 넘으면 오래된 것부터 지웁니다. `0`이면 지우지 않습니다                           |

## 봇 운영자

| 이름       | 기본값 | 설명                                                                                                                            |
| ---------- | ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `OWNER_ID` | 비움   | 봇 운영자를 직접 정할 때만 넣습니다. 디스코드 사용자 ID(숫자 17~20자리, 사용자명이 아닙니다)를 넣고, 여럿이면 쉼표로 구분합니다 |

봇 운영자는 운영자 패널과 `/system` 명령어를 쓸 수 있는 사람입니다.<br>
`OWNER_ID`를 비우면 디스코드 개발자 포털의 앱 소유자(팀이 소유한 앱이면 팀 소유자)가 운영자입니다.<br>
`OWNER_ID`를 넣으면 앱 소유자와 운영자 패널의 운영자 범위 설정은 무시되고, 적은 사람만 운영자가 됩니다. 형식이 틀린 ID는 어떤 사용자와도 맞지 않으며, 봇을 켤 때 경고로 알려 줍니다. 모두 틀려도 앱 소유자로 돌아가지 않으니 운영자가 한 명도 없게 됩니다.

> [!TIP]
> 사용자 ID는 디스코드의 설정 → 고급 → 개발자 모드를 켠 뒤, 내 프로필을 우클릭해 "사용자 ID 복사"로 얻을 수 있습니다.

## 개발 및 테스트용

| 이름       | 기본값 | 설명                                                                                                                                                  |
| ---------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GUILD_ID` | 비움   | 서버 ID(숫자 17~20자리). 넣으면 슬래시 명령어를 그 서버에만 등록합니다. 비우면 봇이 들어간 모든 서버에 등록합니다. 형식이 틀리면 봇이 켜지지 않습니다 |

`GUILD_ID`를 다른 서버로 바꾸거나 다시 비우면, 봇이 이전 서버에 등록했던 명령어를 지웁니다.<br>
반대로 비워 둔 채 쓰다가 `GUILD_ID`를 넣으면, 모든 서버에 등록했던 명령어가 남아 `GUILD_ID`로 정한 서버에서는 같은 명령어가 두 개씩 보입니다(봇을 켤 때 로그로 알려 줍니다).<br>
남은 명령어는 `pnpm run commands --clear-global`로 지웁니다. 다만 이렇게 지우면 `GUILD_ID`를 넣어 둔 동안에는 다른 서버에서 명령어를 쓸 수 없습니다.

## 시크릿 키

`.env`를 만들 때 자동으로 채워지는 값입니다. 직접 넣을 일은 거의 없습니다.

| 이름          | 설명                                                                                                                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SECRETS_KEY` | **[필수]** 대시보드에 저장한 API 키, 쿠키 같은 민감한 값을 암호화하는 키(32바이트 base64). 대시보드 로그인 유지에 쓰는 값도 이 키에서 만듭니다. 비어 있거나 형식이 틀리면 봇이 켜지지 않습니다 |

> [!WARNING]
> `SECRETS_KEY`를 바꾸거나 잃어버리면 대시보드에 저장한 API 키와 쿠키를 읽을 수 없어 다시 입력해야 하고, 대시보드 로그인도 모두 풀립니다.<br>
> 봇을 옮기거나 다시 설치할 때는 기존 `.env`를 그대로 가져가세요. `pnpm run backup`으로 만든 백업에도 `.env`가 들어 있습니다.

직접 만들어야 할 때(실수로 지웠거나, 이미 있던 `.env`에 값이 없을 때) 봇 폴더에서 아래 명령의 출력을 넣으세요.

```bash
# SECRETS_KEY
node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"
```
