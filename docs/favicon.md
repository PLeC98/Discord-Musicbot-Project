# 대시보드 파비콘

운영자 패널의 **꾸미기** 탭에서 그림을 올리면 대시보드의 파비콘(브라우저 탭, 홈 화면 아이콘)으로 사용합니다.
올린 그림이 없으면 봇의 디스코드 프로필 이미지를 사용합니다.

## 올릴 수 있는 그림

- 형식: `.png` · `.webp` · `.jpg` · `.svg`
- 정사각형이고 한 변이 16px 이상일 것(`.svg` 는 둘 다 보지 않음)
  - 정사각형이 아닌 `.svg` 는 자르지 않고 투명 여백을 채워 그립니다.
- 한 장에 10MB 이하, 최대 8장
- 여러 장을 한 번에 올리거나 끌어다 놓을 수 있습니다.
  - 같은 해상도의 그림을 다시 올리면 기존 그림을 바꿉니다(`.svg` 는 `.svg` 끼리).

## 주의사항

- 그림의 해상도는 파일명이 아니라 그림 자체에서 읽어들입니다.
- 올린 그림은 봇이 다시 만들어 저장합니다(래스터는 png 로 바꾸고 메타데이터는 남기지 않습니다).
- 올리거나 지우면 봇을 재시작하지 않아도 바로 적용됩니다.
  - 열려 있는 다른 탭은 브라우저가 아이콘을 캐싱하고 있어 바로 바뀌지 않을 수 있습니다. 그때는 새로고침하세요.

## 이미지 해상도

| 크기            | 쓰이는 곳                                 |
| --------------- | ----------------------------------------- |
| 16 · 32 · 48    | 브라우저 탭 · 북마크                      |
| 180             | iOS 홈 화면                               |
| 192 · 256 · 512 | 안드로이드 홈 화면 추가(웹 앱 매니페스트) |

- 필요한 해상도의 이미지가 없을 경우, 제일 근접한 해상도의 이미지를 늘이거나 줄여 사용합니다.
  - 근접도 측정은 배율을 사용합니다. (180을 만들 때 32는 5.6배, 512는 2.8배라 512)
  - 배율이 동일하면 해상도가 높은 쪽을 사용합니다.
- `.svg`(벡터) 파일이 있으면, 모든 크기를 해당 파일을 사용해 그립니다.
- 크기마다 어떤 그림을 쓰는지는 꾸미기 탭에서 볼 수 있습니다.
- 파비콘 이미지를 한 장만 준비한다면, 512x512 이상의 정사각형 png나 svg를 권장합니다.
  - 작은 크기(16, 32)의 이미지를 따로 준비해두면 브라우저 탭 바에서 표시되는 파비콘이 더 또렷해집니다.
